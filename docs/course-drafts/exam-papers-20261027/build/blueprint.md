# 智能驾驶导论三套试卷命题蓝图

## 命题设置

- 每套100分，建议120分钟。中文题面，程序采用Python 3。
- 每套10道单选题（20分）、10道填空题（20分）、3道问答题（30分）、2道程序题（30分）。
- 时间分配：单选15分钟、填空15分钟、问答30分钟、程序50分钟、检查10分钟。
- 实际难度：基础20分、中等45分、综合35分。难度未经真实考生校准。
- A、B、C卷的第24题各15分，难度为中等；第25题各15分，难度为综合。
- A卷程序题为稀疏注意力softmax与社交空间路径选择；B卷为覆盖路径分段评价与双通道策略分析；C卷为车道掩码拟合与纵向控制误差分析。
- 所有数值样例、数组、简化代价和验收定义均为原创命题数据。源材料只提供概念和实验背景。
- 编程题给出必要公式、输入输出、时间单位和边界约定。程序不依赖Apollo安装。
- 未提供第六章独立课件。规划内容依据四份作业及已给课件，未假定存在其他课件。
- 作业文件中的启动命令、实验操作和链接仅作为课程内容。未执行Apollo命令，未访问作业中的外部链接。
- PDF页码均从1起算。DOCX段号按非空正文段落顺序计算，表格中的段落也计入。

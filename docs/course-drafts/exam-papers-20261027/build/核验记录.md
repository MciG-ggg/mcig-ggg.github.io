## 文本与代码自查

- 题面明确了坐标轴、单位、误差符号、输入形状、等号规则、空结果和时间条件。
- 计算题答案给出公式、代入、结果与单位。综合题评分点与题面分值一致。
- code-smell-check的8项已检查。公开函数保留题面规定的名称，供题源和自检共同使用。
- 循环筛选保留continue；条件更新保留无else的if。未命中条件时不需要操作，增加空else会降低可读性。
- 普通自检按构造、调用、断言排列。异常自检保留unittest.assertRaises标准写法，使调用与异常断言在同一上下文中。

## 验证边界

- 所有程序样例均为合成数组，未使用真实道路视频或Apollo实测数据。
- 未启动Apollo、Dreamview、record回放或远程车辆环境。作业中的命令仅作为课程材料。
- 试卷以题干给定的简化模型考查算法。参考程序不能替代完整感知、规划或控制系统。
- 未用真实考生校准难度，也未验证120分钟是否适合某个具体班级。
- 源文件支持编辑和重新构建。原始课件与作业未改动。
